# Code Review: d6643a90

> feat: Add ChatGPT GPT-5.5 thinking model support for code reviews

## Summary
This commit updates the code review tool to default to the 'gpt-5-5-thinking' model instead of 'claude sonnet 4.6 thinking', adds model selection to the ChatGPT engine payload in electron/providers/chatgpt-engine.js, and includes an undocumented 'oai-last-model-config' extension for extended reasoning when using thinking models. It also extends MODEL_ALIASES in electron/rest-api.cjs to map 'gpt-5-5' and 'gpt-5-5-thinking' to 'chatgpt'. Research confirms GPT-5 series thinking models exist as of 2026 with variants like gpt-5-thinking for advanced reasoning, though some GPT-5.1 thinking models were retired from ChatGPT interfaces in early 2026 but remain API-available; no official docs validate 'oai-last-model-config' or 'effort: extended' as standard payload fields for ChatGPT web API or OpenAI Responses/Chat Completions APIs, which use parameters like reasoning.effort (low/medium/high).
